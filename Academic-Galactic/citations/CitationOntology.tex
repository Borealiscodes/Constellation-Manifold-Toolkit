\section{Citation Ontology}
\label{sec:CitationOntology}

The Academic-Galactic architecture uses a five-class citation ontology to
maintain altitude separation, provenance integrity, and mathematical rigor.
Each citation is tagged with a class superscript.

\subsection{Ontology Classes}

\begin{itemize}
    \item \textbf{Class A — Foundational Mathematics}\\
    Core mathematical sources: category theory, operator algebras, holonomy,
    curvature, spectral geometry, differential geometry.

    \item \textbf{Class B — Applied Geometry / Cognitive Models}\\
    Reserved for NDH, cognitive geometry, and applied manifold models.

    \item \textbf{Class C — Research Compilation / Foundations}\\
    Topos theory, categorical foundations, structural compilations.

    \item \textbf{Class D — Provenance / System Architecture}\\
    Axiom-Quant ecosystem, operator catalog, monograph series, threshold kernel.

    \item \textbf{Class E — Anti-Hallucination / Coherence}\\
    Higher-dimensional algebra, globular coherence, categorical consistency.
\end{itemize}
