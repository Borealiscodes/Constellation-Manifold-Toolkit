\section{The Constitutional Stack}
\label{sec:constitutional-stack}

The Octo Constitution is the governing functor tower that constrains all
geometric, expressive, rendering, governance, stability, directional,
lineage, and identity behavior within the NDH manifold. Each constitutional
layer is represented as an endofunctor acting on the NDH manifold
$\mathcal{M}$.

% ------------------------------------------------------------
% 1. Constitutional Functor Tower
% ------------------------------------------------------------

\subsection{Functor Tower}

The Octo Constitution is defined as the ordered tuple

\[
\mathfrak{C} =
(\mathcal{C}_0, \mathcal{C}_1, \mathcal{C}_2,
 \mathcal{C}_3, \mathcal{C}_4, \mathcal{C}_5,
 \mathcal{C}_6, \mathcal{C}_7)
\]

where each $\mathcal{C}_i$ is an endofunctor

\[
\mathcal{C}_i : \mathcal{M} \to \mathcal{M}.
\]

The ordering of the functors is constitutionally significant and determines
the altitude at which each membrane operates.

% ------------------------------------------------------------
% 2. Pedagogical Constitution (C0)
% ------------------------------------------------------------

\subsection{Pedagogical Constitution}

The pedagogical layer governs explanatory behavior. It is defined as

\[
\mathcal{C}_0 : \mathcal{M} \to \mathbf{Explain}(\mathcal{M})
\]

mapping geometric structures to pedagogical surfaces without altering
manifold identity.

% ------------------------------------------------------------
% 3. Expressive Constitution (C1)
% ------------------------------------------------------------

\subsection{Expressive Constitution}

The expressive layer constrains expressive morphisms in the spectral
adjacency category:

\[
\mathcal{C}_1 \subseteq \mathrm{End}(\mathcal{A}_s).
\]

It governs how NDH may express spectral information.

% ------------------------------------------------------------
% 4. Rendering Constitution (C2)
% ------------------------------------------------------------

\subsection{Rendering Constitution}

The rendering layer constrains projection morphisms in the constitutional
adjacency category:

\[
\mathcal{C}_2 \subseteq \mathrm{End}(\mathcal{A}_c).
\]

It governs how NDH may render constitutional geometry.

% ------------------------------------------------------------
% 5. Governance Constitution (C3)
% ------------------------------------------------------------

\subsection{Governance Constitution}

The governance layer constrains rule morphisms in the operator adjacency

The stability layer imposes curvature bounds on the NDH manifold:

\[
\mathcal{C}_4 : \kappa(x) \le \kappa_{\max}.
\]

It governs drift-neutrality and excitation safety.

% ------------------------------------------------------------
% 7. Direction Constitution (C5)
% ------------------------------------------------------------

\subsection{Direction Constitution}

The direction layer defines a preferred tangent field:

\[
\mathcal{C}_5 : X \to T(X)
\]

mapping each point to its constitutional direction vector.

% ------------------------------------------------------------
% 8. Lineage Constitution (C6)
% ------------------------------------------------------------

\subsection{Lineage Constitution}

The lineage layer governs reversible adjacency between NDH and external
systems:

\[
\mathcal{C}_6 : \mathcal{M} \leftrightarrow \mathcal{M}'.
\]

It enforces non-absorptive reconstruction and prohibits inheritance.

% ------------------------------------------------------------
% 9. Identity Constitution (C7)
% ------------------------------------------------------------

\subsection{Identity Constitution}

The identity layer defines the identity fibration

\[
\pi : \mathcal{M} \to I
\]

where $I$ is the identity manifold. All constitutional functors must satisfy

\[
\pi \circ \mathcal{C}_i = \pi.
\]

Identity is preserved across all constitutional transformations.

% ------------------------------------------------------------
% 10. Constitutional Compatibility
% ------------------------------------------------------------

\subsection{Compatibility}

All constitutional functors commute with the Quantum Sponge sheaf:

\[
\mathcal{C}_i(\mathcal{Q}) = \mathcal{Q}.
\]

This ensures that reconstruction behavior remains constitutionally safe.
