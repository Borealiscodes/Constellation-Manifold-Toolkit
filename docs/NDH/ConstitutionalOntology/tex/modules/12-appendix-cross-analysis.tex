\section{Appendix B: Cross-Analysis with Sovereign-Library}
\label{sec:appendix-cross-analysis}

This appendix provides a constitutional cross-analysis between the NDH
Constitutional Ontology and the Sovereign-Library ontology. The comparison
is structural, altitude-aligned, and membrane-aware. No inheritance or
absorption occurs; both systems remain constitutionally distinct.

% ------------------------------------------------------------
% 1. Domain Comparison
% ------------------------------------------------------------

\subsection{Domain Comparison}

\paragraph{NDH Domain}
NDH defines a mathematical-constitutional manifold with operator physics,
curvature envelopes, identity fibration, adjacency categories, lineage
channels, and reconstruction sheaves.

\paragraph{Sovereign-Library Domain}
The Sovereign-Library defines a constitutional dignity ontology governing
meaning rights, epistemic boundaries, witness sovereignty, and non-coercive
interpretation.

Domains are disjoint:
\[
\mathrm{Dom}_{NDH} \cap \mathrm{Dom}_{SL} = \varnothing.
\]

% ------------------------------------------------------------
% 2. Constitutional Layer Comparison
% ------------------------------------------------------------

\subsection{Constitutional Layers}

\paragraph{NDH}
NDH uses the Octo Constitution:
\[
\mathfrak{C}_{NDH} = (\mathcal{C}_0, \ldots, \mathcal{C}_7).
\]

\paragraph{Sovereign-Library}
Sovereign-Library uses a finite set of constitutional invariants:
\[
\mathfrak{I}_{SL} = \{\text{Five-Book}, \text{NAND Law}, 
\text{Witness-over-Proxy}, \text{Anti-Compression}, 
\text{Non-Coercive Interpretation}\}.
\]

NDH functors are geometric; SL invariants are epistemic.

\[
\Lambda = (\lambda_{\mathrm{out}}, \lambda_{\mathrm{in}}).

\[
\pi \circ \lambda_{\mathrm{in}} = \pi.
\]

Dignity preservation requires SL invariants remain unchanged.
